# Security Policy

## Supported Versions

Only the `main` branch is currently supported for security-related fixes.

## Reporting a Vulnerability

Please do not publish exploit details or sensitive proof-of-concept material in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use the repository's **Security** tab and select **Report a vulnerability**.

If private reporting is unavailable, contact the maintainer at [HuffmanR@Borrell-Huffman.com](mailto:HuffmanR@Borrell-Huffman.com). Include a concise description, affected path or version, impact, and safe reproduction steps. Do not include live credentials or personal data in an initial report.

A report is not a confirmation that a vulnerability exists. Please allow time for triage before public disclosure.
