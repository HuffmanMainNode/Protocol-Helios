# Security Policy

## Supported Versions

Only the `main` branch is currently supported for security-related fixes. No response-time or remediation SLA is published.

## Reporting a Vulnerability

Please do not publish exploit details, credentials, private data, or sensitive proof-of-concept material in a public issue.

If GitHub private vulnerability reporting is enabled for this repository, use the repository's **Security** tab and select **Report a vulnerability**.

If private reporting is unavailable, contact the maintainer through the public contact route on the [HuffmanMainNode GitHub profile](https://github.com/HuffmanMainNode) and request a private reporting channel. Include a concise description, affected path or version, impact, and safe reproduction steps. Do not include live credentials or personal data in an initial report.

This repository does not currently advertise a dedicated encrypted security endpoint or guaranteed response time. A report is not a confirmation that a vulnerability exists. Please allow time for triage before public disclosure.
